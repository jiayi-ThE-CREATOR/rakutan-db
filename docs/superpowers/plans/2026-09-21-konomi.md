# 「配点でしぼる」を好みの重さにする 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** レールの「配点でしぼる」を、`score.py` の既定（テスト50・発表20・レポート15・出席15・小テスト10）をそのまま出す「好みの重さ」の目盛りにし、しぼり込みは各軸の ✕ が引き継ぐ。

**Architecture:** 好みはブラウザの中だけ（`score.py` は触らない）。しぼり込みの ✕ は**いまの caps の仕組みをそのまま使う**（0 か 100 だけを入れる）ので、`server.py`・条件チップ・URL の `cap_*` は変えなくてよい。採点（Task 1）→ 画面（Task 2）→ 門（Task 3）→ 文言（Task 4）→ 引き継ぎ（Task 5）の順。どのタスクのコミットでも既存テストが全件通る。

**Tech Stack:** 素の JavaScript（ビルドなし）、テストは `node tools/test_*.mjs`（Playwright）と `python3 tools/test_*.py`

**Spec:** `docs/superpowers/specs/2026-09-21-konomi-design.md`

## Global Constraints

- `python3` の実体は `/Library/Frameworks/Python.framework/Versions/3.14/bin/python3`
- 作業場所は worktree `.worktrees/konomi`、ブランチ `feat/konomi-toggles`。**本体の `main` を動かさない**。push・PR・マージは wang の確認を取ってから
- **`score.py` は触らない。** 採点の正本は1つのまま。好みはブラウザ側だけ
- 好みの既定値は `score.py` と同じ **テスト 50 ／ 発表 20 ／ レポート 15 ／ 出席 15 ／ 小テスト 10**
- 効かせ方は**負担の倍率**（`楽さ' = 100 − (100 − 楽さ) × いまの目盛り ÷ 既定`）。重みとして使わない
- しぼり込みの ✕ は `state.caps` を 0（＝しぼる）か 100（＝しぼらない）にするだけ。中間の値はもう作らない
- 目盛り（好み）は塞がない。✕ は「見えるが、動かすには LINE 登録」
- band は好みで数え直す。閾値は既定と同じ 84/71/65
- JS テストは静的サーバ（`python3 -m http.server <port> --directory web`）に向けて流す。`tools/test_kuchikomi_modal.mjs` は main でも落ちている既知の NG

- [ ] **Step 4: 相性度と band を好みで計算し直す**

`web/assets/app.js` の `function matchLocal(r){` の中、`  const axes = r.axes;` の**直後**に足す:

```js
  /* 好みを反映した相性度。式は score.py の aishoudo と同じで、各軸の「負担」に
     prefMult を掛けるところだけが違う。**score.py は触らない**（採点の正本は1つ。
     好みはブラウザの中だけの話）。 */

    ? v : Math.max(0, Math.min(100, 100 - (100 - v) * prefMult(k)));
```

続けて、同じ関数の中（`const axes = r.axes;` の直後に入れた `bend` の下）に足す:

```js
  const V = {};
  for (const k of Object.keys(axes)) V[k] = bend(axes[k].value, k);
  const OW = { presentation:20, report:15, attendance:15, quiz:10 };
  const present = r.present || [];
  const ws = present.reduce((s, k) => s + (OW[k] || 0), 0);
  const other = (!present.length || ws <= 0) ? 100
    : present.reduce((s, k) => s + V[k] * (OW[k] || 0), 0) / ws;
  const examShare = (state.pref.exam ?? PREF_DEFAULT.exam) / 100;
  const factLayer = examShare * V.exam + (1 - examShare) * other;
  const feel = r.feel || {};
```

- [ ] **Step 5: URL と localStorage で往復する**

`web/assets/app.js` の `syncCaps()` の下に足す:

```js
/* 好みを URL（?w=exam:25,report:30）と localStorage に往復させる。
   既定のままの軸は書かない ―― 触っていない人の URL を長くしない。 */
function syncPref(){
  const diff = Object.keys(PREF_DEFAULT)
    .filter(k => state.pref[k] !== PREF_DEFAULT[k])
    .map(k => `${k}:${state.pref[k]}`);
  const u = new URL(location.href);
  if (diff.length) u.searchParams.set("w", diff.join(","));
  else u.searchParams.delete("w");
  history.replaceState(history.state, "", u.pathname + u.search + u.hash);
  try {
    if (diff.length) localStorage.setItem(PREF_KEY, JSON.stringify(state.pref));
    else localStorage.removeItem(PREF_KEY);
  } catch (e) {}
}

/* 開いたときに好みを戻す。URL が最優先（共有されたリンクを開いた人は
   自分の保存より、そのリンクの並びを見る）。 */
function loadPref(){
  let from = null;
  const q = new URLSearchParams(location.search).get("w");
  if (q){
    from = {};
    for (const part of q.split(",")){
      const [k, v] = part.split(":");
      if (k in PREF_DEFAULT && Number.isFinite(+v)) from[k] = Math.max(0, Math.min(100, +v));
    }
  } else {
    try { from = JSON.parse(localStorage.getItem(PREF_KEY) || "null"); } catch (e) {}
  }
  if (from) state.pref = { ...PREF_DEFAULT, ...from };
}
```

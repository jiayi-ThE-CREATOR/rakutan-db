## 11. 追記（2026-09-03 その3）― GAS のコードが届いた。原因が確定

`doPost` は **固定配列で書き込む型（§3 の A）**だった。書き込み配列は18要素で、
`sel.subject.review.exam`（持ち込み）の次がもう `reportPresence`。
**`examDifficulty` を読む行が最初から無い。**

```js
sel.subject.review.exam || "",              // ← 「テスト」列
                                            // ← ここに難易度が無い
sel.subject.review.reportPresence || "",    // ← 「レポート有無」列
```

送信側（`kuchikomi.js:782`）も Worker（`worker/index.js:724-741`）も正しく、
**GAS の配列に1行足りないだけ**。届いた難易度は `data` の中に在るのに、誰も読まずに捨てていた。

コードの写しを repo に置いた（**これまで GAS の写しはどこにも無かった**）:

- `tools/gas/kuchikomi_before_20260903.gs` … 変更前。**戻すときはこれを貼り戻す**
- `tools/gas/kuchikomi_after_20260903.gs` … 変更後。差分は2か所だけ

```bash
diff tools/gas/kuchikomi_before_20260903.gs tools/gas/kuchikomi_after_20260903.gs
```

### 変更の中身（2か所・どちらも配列に1つ足すだけ）

1. 見出しの自動作成の配列に `"テストの難易度"` を追加（`"テスト"` の直後）
2. 書き込む行の配列に `Number(sel.subject.review.examDifficulty) || "",` を追加（同じ位置）

**`Number()` を挟む理由**: フォームは文字列（`"7"`）で送ってくる。
テストが無かった回は `null` で届き、`Number(null)` は `0` → 偽 → `""`（空欄）になる。
難易度は 1〜10 なので、`0` になるのはテストが無かった回だけ。**0 を書かないのが大事**
（「テスト無し」と「難易度0＝簡単」が区別できなくなる）。

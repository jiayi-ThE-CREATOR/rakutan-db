# 次の版に載せるもの（仮置き場）

**ここは正本ではない。** 出したあとの正本は `web/assets/version.js` の `RELEASES` ひとつだけ。
ここに置くのは「載せると決まったが、まだ本番の版に入っていないもの」だけ。

## 使い方

1. 本番に何か出すとき、版に載せるかを利用者に聞く（判定は `CLAUDE.md`「版に載せるかの判定」）
2. 「載せる」になったら、下の一覧に1行足す
3. **毎週水曜**、溜まったものを `RELEASES` の先頭に1件の版としてまとめて移し、この一覧を空にする
   - `new` が1件でもあれば MINOR（1.2 → 1.3）、1件も無ければ PATCH（1.2 → 1.2.1）
   - **1件も無い週は版を切らない**（日付だけ進んだ空の版を出さない）
4. 移したら `node tools/test_version.mjs` を通す

初回は **2026-10-07（水）**。9月のあいだは重要なものだけを、溜まった時点で出す。

書き方（tag は `new` / `improve` / `fix` の3つだけ）:

```
- [new] 〜〜（2026-09-05 本番）
```

利用者が読む文なので、内部の言い方（リファクタ・CI・API 名）は書かない。
**「その人の画面で何が変わったか」だけ**を書く。

## 次の水曜に出すもの

- [new] 授業の「配点」でしぼれるようになりました。出席・期末テスト・小テスト・レポートが成績の何%かを指定して探せます
- [new] 小テストの配点を出席と分けて出すようになりました。「出席は緩いけれど毎週小テストがある」授業が見分けられます
- [improve] 「出席なし」などの条件を押すと、対応する配点のつまみが動くようになりました
- [new] 左の絞り込みを畳めるようになりました。条件と一覧のあいだにある矢印を押すと畳めて、一覧が広がります
- [improve] 科目を選んでいないあいだは、一覧を画面の中央に出すようになりました。右側が大きく空いて見えていたのを詰めています（PC）
- [new] 選んだ科目の詳細を ✕（または Esc キー）で閉じられるようになりました。閉じると一覧だけの画面に戻ります（PC）
- [fix] 「成績評価の内訳」を、シラバスに書いてあるとおりの項目名と数字で出すようになりました。これまでは4つに分類し直して出していたので、発表だけで成績が付く授業が「レポート」と表示されたり、分類できない項目が「不明」に消えたりしていました
- [improve] 成績評価の表が空だった授業で、シラバス本文に書かれた配点が読めるようになりました。「授業で指示する課題類（80％）と授業での議論への貢献度（20％）」のような記述をそのまま出しています

# 次の版に載せるもの（仮置き場）

**ここは正本ではない。** 出したあとの正本は `web/assets/version.js` の `RELEASES` ひとつだけ。
ここに置くのは「載せると決まったが、まだ本番の版に入っていないもの」だけ。

## 使い方

1. 本番に何か出すとき、版に載せるかを利用者に聞く（判定は `CLAUDE.md`「版に載せるかの判定」）
2. 「載せる」になったら、下の一覧に1行足す
3. **毎週水曜**、溜まったものを `RELEASES` の先頭に1件の版としてまとめて移し、この一覧を空にする
   - `new` が1件でもあれば MINOR（1.2 → 1.3）、1件も無ければ PATCH（1.2 → 1.2.1）
   - **1件も無い週は版を切らない**（日付だけ進んだ空の版を出さない）
4. 移したら `node tools/test_version.mjs` を通す

初回は **2026-10-07（水）**。9月のあいだは重要なものだけを、溜まった時点で出す。

書き方（tag は `new` / `improve` / `fix` の3つだけ）。
**太字の見出し｜説明** の2段で書く（`｜` で区切る。説明は省いてよい）:

```
- [new] 左の絞り込みを畳める｜条件と一覧のあいだの矢印を押すと畳めます｜/#grip
```

- 見出しは **20文字まで**。「〜するようになりました」は入れない（全部そうなので情報が無い）
- 最後に `/` で始まるパスを足すと「見てみる →」のリンクが出る。**新しく増えたもの**に付ける。
  サイトの中だけ・**いま行ってもその機能が見えるもの**だけ（飛び先が空だとリンクは二度と押されない）。
  水曜に `RELEASES` へ移したら `node tools/test_version_links.mjs http://localhost:8140` を通す

利用者が読む文なので、内部の言い方（リファクタ・CI・API 名）は書かない。
**「その人の画面で何が変わったか」だけ**を書く。

### 主打（版の先頭にカードで出る 1〜3件）

ダイアログを開いた人が最初に見るのは主打カードだけで、それ以外は畳まれている。
**1つの版につき 1〜3件**（0件でも4件でも `tools/test_version.mjs` が落ちる）。
主打にするものは `★` に続けてアイコン名・見出し・本文を `｜` で区切る:

```
- [improve] ★score｜重さの出し方を作り直しました｜テストの有無をいちばん大きく見ます
```

- 見出しは **24文字**、本文は **60文字** まで（超えると落ちる）
- アイコンは `web/assets/version.js` の `ICONS` にある名前だけ
  （`score` `search` `filter` `calendar` `star` `chat` `data` `mobile` `link` `check` `sparkle`）
- 主打にした項目は畳みの一覧には**出ない**。だから主打の文は、それ単体で意味が通るように書く
- 選び方の考え方は `CLAUDE.md`「主打 ―― 版の先頭に大きく出る1〜3件」
